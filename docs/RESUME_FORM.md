# 정형 이력서 양식 규격

규칙 파서(`apps/api/app/extraction/parse.py`)는 이 양식을 기준으로 동작한다. 양식을 바꾸면 파서의 `SECTIONS`, `IDENTITY_KEYS`, `COLUMNS` 별칭을 함께 갱신하고 정확도 테스트(`test_m4_extraction.py`)를 다시 돌린다.

## 형식
- PDF(텍스트형, 20페이지 이하, 암호화·스크립트 없음) 또는 DOCX(매크로·외부 참조 없음), 10MB 이하
- HWP와 스캔 이미지 PDF(OCR 필요)는 지원하지 않는다 (OPEN_QUESTIONS #3)

## 구조
섹션 제목은 단독 줄로 쓴다(`[학력]`, `학력`, `■ 학력` 모두 인식). 표에는 테두리가 있어야 한다(PDF 표 인식에 필요).

| 섹션 | 제목 별칭 | 내용 |
|---|---|---|
| 인적사항 | 인적사항, 기본정보, 개인정보 | `키 \| 값 \| 키 \| 값` 표, 또는 `키: 값` 줄 |
| 학력 | 학력, 학력사항 | 표: 학교 · 전공 · 학위 · 입학 · 졸업 |
| 경력 | 경력, 경력사항 | 표: 회사 · 직무 · 시작 · 종료 · 담당업무 |
| 기술 | 기술, 보유기술, 기술스택 | 표: 기술 · 숙련도(초급/중급/고급/전문가, 상/중/하) · 경력(년) |
| 자격 | 자격, 자격증, 자격/어학 | 표: 자격증 · 발급기관 · 취득일 |
| 자기소개 | 자기소개, 자기소개서 | 자유 서술(암호화 저장) |

인적사항 키: 이름(성명) · 생년월일 · 성별 · 휴대폰(연락처, 휴대전화) · 이메일 · 주소

## 자동 처리
- **주민등록번호/외국인등록번호**: 패턴(`######-#######`)이나 "주민등록번호" 키가 보이면 값을 버린다. 파싱 전에 텍스트에서 지우고 `rrn_removed` 경고만 남긴다. 수동 수정으로 입력하려 해도 거부된다.
- **정규화**: 전화번호는 E.164, 이메일은 소문자, 날짜는 `YYYY-MM` / `YYYY-MM-DD`로 바꾼다. 기술명은 별칭 사전(`app/skills.py`)으로 표준화한다(`js`→`JavaScript`, `리액트`→`React`).
- **사진**: 문서 안 이미지 가운데 세로형(높이/너비 1.1~1.7) 첫 이미지를 증명사진으로 본다. JPEG로 다시 인코딩해 EXIF·GPS를 지우고 600×800 이하로 줄인 뒤 암호화해 저장한다.

## 정확도
합성 이력서 20건(PDF 10, DOCX 10, 580개 필드)에서 100%가 나왔다. 기준은 95% 이상이다.
